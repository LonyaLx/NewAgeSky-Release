【一句话简介】
以“资源生产方式升级”为主线的空岛科技整合包：从空岛起步，经历筛矿、农业、蜜蜂、工厂化、ME 网络与 EMC，最终挑战 ProjectE 困难模式、Avaritia 终局和 ME 创造存储元件。

【短简介】
《天工创世》是一款面向 Minecraft 1.21.1 的 NeoForge 空岛科技整合包。整合包包含 216 个模组、29 个任务章节和 945 个 FTB 任务，对空岛材料来源、ProjectE EMC、终局配方与自动化流程进行了大量定制。你将围绕资源生产方式升级建立生产线，从早期手筛逐步发展到农业、蜜蜂、工厂、ME 网络和 EMC，最终完成创造物品阶段链与 ME 创造存储元件。

【整合包介绍】
《天工创世》不是单纯把大量科技模组堆在一起，而是围绕“资源从哪里来、如何量产、怎样升级生产方式”重新设计了空岛发展路线。

前期，你需要从最基础的资源获取开始，逐步搭建筛矿、种植和生物资源体系；中期，随着 Create、Mekanism、EnderIO、Industrial Foregoing、Powah、沉浸工程、气动工艺等模组接入，资源生产会从人工操作转向工厂化与自动化；后期，AE2、AdvancedAE、ExtendedAE、MEGA Cells 等存储与物流模组将成为核心，最终进入 ProjectE、Re-Avaritia 与 PackagedAvaritia 的终局阶段。

整合包内置完整的 FTB Quests 任务线。29 个章节、945 个任务会持续给出明确的发展目标，同时保留科技整合包自由规划和自动化改造的空间。主线章节注重具体物品与阶段目标，专题章节则覆盖 AE2、EnderIO、Just Dire Things、Neo Eco AE、能源系统等内容。

ProjectE 在本包中采用严格 EMC 模式：只保留基础矿物和基础加工物的 EMC，关闭配方自动推导，机器产物与无限资源不提供 EMC。贤者之石、交换桌、平板、暗物质、红物质、收集器、继电器与凝聚器等核心物品均改为更高难度的 tier 4 配方，避免 EMC 过早破坏整体进度。

终局阶段接入 Re-Avaritia 与 PackagedAvaritia。十件创造物品会组成有序阶段链，从创造能源立方逐步推进到龙之研究、气动工艺与 JDTe，最终通过创造收敛核心合成 ME 创造存储元件。

【核心特色】
1. 完整的空岛科技发展路线
从基础筛矿和资源获取开始，经过农业、蜜蜂、工业机器与自动化物流，最终进入 ME 网络、EMC 和创造物品终局。

2. 29 章、945 个任务
任务书覆盖主线发展与多个大型模组专题。主线 1—5 章每章 40 个具体物品任务，共 200 个主线物品任务，内部及专题章节之间没有物品重叠。

3. ProjectE 严格 EMC
关闭配方自动推导，限制基础资源以外的 EMC 获取，机器和无限资源不会提供 EMC。ProjectE 核心内容需要搭建高阶自动化产线才能推进。

4. 定制化终局链
ProjectE 核心物品与创造物品采用 Extreme Package Crafter 执行的 tier 4 配方。十件创造物品组成连续阶段链，最终目标为 ME 创造存储元件。

5. 空岛材料来源补全
已补充 Neo Eco、AE2 压印模板、门瑞欧、Draconium、坚固蜂笼、终极锭、锇、11 种碎矿、蜜脾、农业种子等材料来源。原版 17 种锻造模板均已添加不依赖堡垒和遗迹的有序配方。

6. 大量配方与数据包调整
包含 ProjectE 严格 EMC 数据包、11 个终局自定义物品及大量 KubeJS 配方调整。发布前测试结果为 KubeJS 0 错误、0 失败配方，本次新增 JEI 配方 0 broken。

7. 中文与性能优化
内置中文资源包与 I18n 更新模组，并加入 Sodium、Iris、ModernFix、FerriteCore、ImmediatelyFast、EntityCulling、BadOptimizations 等性能优化模组。默认提供 Complementary Reimagined 光影，可根据电脑性能自行关闭。

【推荐游玩流程】
第一阶段：空岛起步
建立最基础的资源获取体系，完成初期筛矿、种植与任务目标，逐步摆脱完全依赖手动获取资源的阶段。

第二阶段：农业与生物资源
使用 Mystical Agriculture、Productive Bees、Botany Pots、Bonsai Trees 等模组建立可再生资源来源。

第三阶段：工业化生产
接入 Create、Mekanism、EnderIO、Powah 等科技模组，把零散机器发展为连续生产线。

第四阶段：ME 网络与自动化
搭建 AE2 存储、合成与物流系统，使用 AdvancedAE、ExtendedAE、MEGA Cells、LaserIO、SFM 等模组提高自动化程度。

第五阶段：EMC 与高阶资源
在基础资源体系稳定后进入 ProjectE。由于本包关闭自动推导并限制 EMC，建议先完成自动化产线，再推进 ProjectE 核心物品。

第六阶段：Avaritia 与创造终局
搭建 Package Encoder → Recipe Holder → Packager → Extreme Package Crafter 产线，按照 Chain 1—10 的顺序完成创造物品阶段链。

最终目标：合成 ME 创造存储元件。

【安装教程】
1. 不要解压整合包。
2. 打开 PCL2 或 HMCL。
3. 选择“安装整合包”或“导入整合包”。
4. 选择文件：天工创世-1.0.0-CurseForge.zip。
5. Java 选择 Java 21。
6. 启动器会自动安装 NeoForge 21.1.249。
7. 首次安装需要联网，启动器会下载 166 个远程模组；另有 50 个模组已包含在整合包内。
8. 安装完成后，建议为游戏分配 8 GB 或更多内存。
9. 首次启动请耐心等待模组加载与资源初始化。
10. 进入游戏后，打开 FTB Quests 任务书开始游玩。

【创建空岛世界】
新建世界 → 点击“更多世界选项” → 世界类型选择 Skyblock（Skyblock Builder） → 创建世界。

请不要直接使用普通世界类型，否则无法获得本整合包预期的空岛体验。

【配置建议】
最低配置建议：4 核处理器、16 GB 内存、独立显卡、固态硬盘。
推荐配置：6 核或更高处理器、16 GB 以上内存、中端以上独立显卡、固态硬盘。
游戏内存分配：建议 8 GB 或更多。
Java：必须使用 Java 21。
光影：电脑性能不足时，可在视频设置中关闭 Complementary Reimagined，或降低光影质量。

【常见问题】
Q1：整合包需要解压吗？
不需要。请在启动器中选择“导入/安装整合包”，然后直接选择 ZIP 文件。

Q2：启动时一直下载模组怎么办？
首次安装需要下载 166 个远程模组，请保持网络稳定。如果下载中断，重新执行安装或更换启动器下载源。

Q3：启动时报 Java 版本错误怎么办？
请将启动器使用的 Java 设置为 Java 21，并确认启动器实际调用的就是这个 Java。

Q4：为什么没有空岛？
请新建世界，在“更多世界选项”中将世界类型设置为 Skyblock（Skyblock Builder）。

Q5：JEI 里看到的配方比任务书进度简单，可以提前做吗？
可以自由探索，但部分核心配方和材料来源经过重新设计。建议优先遵循任务书推进，避免因跳阶段导致材料链不完整。

Q6：可以自行更新模组吗？
不建议。整合包包含大量 KubeJS 配方、ProjectE EMC 与终局魔改，直接更新核心模组可能导致任务、配方或进度失效。

Q7：可以用于服务器吗？
本整合包主要面向单人游玩，未提供独立服务端整合包。用于服务器前请自行剔除纯客户端模组并测试兼容性。

Q8：进入游戏后卡顿怎么办？
先关闭光影，再检查内存分配。建议使用固态硬盘，并确保分配内存不少于 8 GB。
